HiiFest menyatukan ribuan event yang berlangsung di seluruh Indonesia — mulai dari malam musik langsung di Jakarta hingga workshop kesehatan di Bali. Baik Anda mencari acara networking, konferensi teknologi, atau festival seni akhir pekan, direktori event HiiFest memudahkan Anda menelusuri, menyaring, dan menemukan pengalaman yang sesuai dengan minat Anda.

## Telusuri semua event

Buka [platform.hiifest.app/events](https://platform.hiifest.app/events) untuk melihat direktori event lengkap. Halaman ini memuat feed real-time event mendatang di seluruh Indonesia, ditampilkan sebagai kartu dengan nama event, tanggal, lokasi, dan gambar sampul. Gulir daftar atau langsung beralih ke tampilan yang sudah disaring menggunakan opsi yang dijelaskan di bawah ini.

## Saring event untuk menemukan yang paling sesuai

HiiFest menyediakan tiga lapis filter yang bisa Anda gabungkan untuk mempersempit hasil dengan cepat.

### Saring berdasarkan format

Pilih cara Anda ingin menghadiri:

<CardGroup cols={3}>
  <Card title="Semua" icon="globe">
    Tampilkan semua event tanpa memandang format — tampilan default.
  </Card>
  <Card title="Tatap muka" icon="location-dot">
    Event yang Anda hadiri di venue fisik di suatu lokasi di Indonesia.
  </Card>
  <Card title="Virtual" icon="video">
    Event online yang dapat Anda ikuti dari mana saja dengan koneksi internet.
  </Card>
</CardGroup>

### Saring berdasarkan kota

Pilih salah satu kota unggulan untuk menampilkan event hanya di lokasi tersebut:

- **Jakarta** — ibu kota dan pusat event terbesar di Indonesia
- **Bali** — terkenal dengan festival, retret kesehatan, dan kumpul kreatif
- **Surabaya** — skena yang berkembang untuk konferensi bisnis dan event komunitas
- **Bandung** — populer untuk musik, seni, dan pengalaman gaya hidup

### Saring berdasarkan kategori

Persempit hasil Anda ke jenis event tertentu menggunakan filter kategori:

| Kategori | Apa yang dapat diharapkan |
|---|---|
| **Music** | Konser, DJ night, penampilan langsung |
| **Technology** | Konferensi, hackathon, peluncuran produk |
| **Workshop** | Sesi pengembangan keterampilan langsung |
| **Networking** | Acara profesional dan kumpul komunitas |
| **Arts & Culture** | Pameran, festival budaya, teater |
| **Wellness** | Retret yoga, meditasi, event kesehatan |
| **Lifestyle** | Festival kuliner, peragaan busana, pop-up market |
| **Sports** | Turnamen, fun run, event kebugaran |
| **Comedy** | Stand-up night, pertunjukan improv, festival komedi |
| **Business** | Pameran dagang, pertemuan investor, KTT kewirausahaan |
| **Education** | Seminar, program pelatihan, simposium akademik |

<Tip>
  Terapkan filter dari beberapa grup sekaligus — misalnya, atur **City → Bali**, **Format → In-Person**, dan **Category → Wellness** untuk menemukan event wellness tatap muka yang berlangsung di Bali. Menggabungkan filter memberikan hasil yang paling presisi.
</Tip>

## Event unggulan di halaman utama

Saat Anda pertama kali mengunjungi [platform.hiifest.app](https://platform.hiifest.app), halaman utama menampilkan pilihan kurasi **Featured Experiences** — event pilihan yang sedang tren, baru tayang, atau dipromosikan oleh penyelenggara. Periksa bagian ini secara rutin agar tidak ketinggalan event yang banyak diminati sebelum tiketnya habis.

## Simpan event untuk nanti

Menemukan event yang menarik tapi belum siap membeli? Klik ikon **Save** (bookmark) pada kartu event mana pun untuk menambahkannya ke wishlist Anda. Akses event yang telah Anda simpan kapan saja dari dasbor attendee Anda di bawah **Saved Events**. Anda dapat meninjau detail event dan langsung menuju halaman tiket saat siap untuk membeli.
